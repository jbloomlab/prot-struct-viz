# Antigenic regions of influenza H3 hemagglutinin

The same structure and the same coloring as the previous view, with the host N-glycans
taken away. Several of them stood over an antigenic region — a real glycan is bulkier and
more mobile than the few modeled sugars drawn here, which is why glycosylation is one of
the ways this protein keeps antibodies off. This is the surface underneath them.

- **red** — site A
- **blue** — site B
- **green** — site C
- **purple** — site D
- **orange** — site E
- **light gray** — HA1, not in a defined antigenic region
- **mid gray** — HA2
- **black** — the LSTc receptor analogue

The receptor analogue stays. Chemically it is a glycan like the ones just removed, and this
view does hide glycans — it survives only because the view's CSV names it, and a residue
named in the CSV is drawn whatever the heteroatom options say. It is worth keeping as the
landmark for the membrane-distal tip of each protomer, where the antigenic regions are.
